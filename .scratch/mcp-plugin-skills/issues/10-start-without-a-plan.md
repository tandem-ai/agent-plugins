# start on a project without a Tandem plan
Type: grilling
Status: resolved

## Question

Some projects have their plan outside Tandem (Notion database, tracker container read where it lives) or no plan yet. `start` step 3 assumes phases and tasks. What does the opening show in those cases — the brief's next steps only, the tracker's rows, an offer to import — and does the skill say so explicitly?

## Answer

Moot: the `start` skill is removed. The plugin does not prescribe how a session on a project begins.
