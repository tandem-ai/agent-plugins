# Tandem

The `tandem` MCP server is the memory of the user's customer projects (people, decisions, plan, conversations, time). It exposes two tools: `search_capabilities` (find the capability for a job, with its full contract) and `execute_capability` (run it). Read `reference/tandem-mcp.md` before the first call.

Skills in `skills/`: `sync` (save the session into the project as a document), `setup` (onboard up to a first project).
