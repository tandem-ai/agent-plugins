# Session record — template

Send this shape as the `content` of `add_context`. Keep the headings; drop a section only when it is empty.

```
Work session — <project name> — <YYYY-MM-DD> — <client, e.g. Claude Code> — <duration, e.g. 2h10>

## Worked on
- <task name> (<status after this session>): <one line on what was done>

## Decisions
- <decision>, because <reason>. <Who was involved or which conversation it follows, if any.>

## Delivered
- <PR / file / configuration / document>, <one line>

## Assumptions to confirm with the customer
- <assumption> — why it was taken, who should confirm

## Open questions
- <question> — for <person or team>

## Blockers
- <blocker> — what would unblock it

## Next steps
- <next action>, <by whom / when if known>
```

Write it for a teammate who was not there. Facts, past tense, no code, no secrets, no transcript.
